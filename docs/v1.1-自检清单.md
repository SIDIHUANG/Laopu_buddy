## 1. 启动器自检段（应 5 段都有内容）

启动器会等最多 12 秒再打印自检段。**逐段确认不是空的**：

- [ ] `[1] 进程`：有 `presage-pet.exe` 一行（说明进程活着）
- [ ] `[2] 托盘注册结果`：**有内容**
      - 这台机器预期是 `NIM_ADD without-icon ok=0 err=5`（已降级为已知限制，不算失败）
      - 这一版起**不再每次启动都弹气泡提示**，所以看不到提示是正常的
- [ ] `[3] 关键状态`：有 `[env] 提权=否` 和 `boot ok states=12`
- [ ] `[4] 几何 / 素材`：有 `[geom:` 开头的一行，且里面有
      **`裁掉=0px`**、**`出屏=0px`**、**`气泡出框=0px`** 三个数
- [ ] `[4b] 设置窗口 / 桥接`：**这一节是新增的**，抓两类故障的第一现场
      - 不该有 `[settings] 创建窗口失败`（有的话设置窗口就是打不开的）
      - 不该有 `[跳过 undefined` / `ERR_MODULE_NOT_FOUND`
- [ ] `[i] 桥接就绪 ok=True DSH 会话=N` 这一行有出现（没有 node 时会跳过，属正常）
- [ ] `[5] pet.err.log 末尾`：显示 `(空)` 最好；有内容请照抄给我
- [ ] 最后一行 `完整日志:` 指向的路径**确实存在**

> 上一次你的 `[2]`~`[5]` 全空，是因为桌宠把日志写到了 `v1\runtime\`，
> 而启动器只在 `<根>\runtime\` 找。已修（现在两个目录都会找）。所以这一段
> **本身就是回归测试**：只要不再全空，就说明修对了。
