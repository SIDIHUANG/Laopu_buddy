# v1.1 自检清单（用户执行 · 逐条打勾）

> 目的：确认 v1.1 真的修好了「角色被窗口裁掉 / 气泡跑出窗口 / 右键菜单被裁」这三类问题。
> 一条一条来，**发现不对就停在那条并记下现象**（现象比结论有用）。
> 全部通过的话，这份清单可以直接当验收记录。

## 0. 准备（30 秒）

- [ ] **先退出现在这只桌宠**：右键她 → 退出；或按 `Ctrl+Alt+Q`；都不行就
      `taskkill /im presage-pet.exe /f`
- [ ] 确认没有残留进程（任务管理器里搜 `presage-pet`）
- [ ] 双击 **`v1\启动桌宠.bat`** —— 这个包现在**是自包含的**，
      不需要工程根目录；`v1\BUILD.txt` 里记着 exe / bat / 文档的 SHA256，可核对版本
      （根目录那份 `启动桌宠.bat` 是同一份逻辑的工程版，两个入口等价）
- [ ] `-Diag` 会多停 30 秒，第一次验证建议加
- [ ] **不要用「以管理员身份运行」**（提权会同时打掉托盘和画面，这是实测结论）

## 1. 启动器自检段（应 5 段都有内容）

启动器会等最多 12 秒再打印自检段。**逐段确认不是空的**：

- [ ] `[1] 进程`：有 `presage-pet.exe` 一行（说明进程活着）
- [ ] `[2] 托盘注册结果`：**有内容**
      - 这台机器预期是 `NIM_ADD without-icon ok=0 err=5`（已降级为已知限制，不算失败）
      - 这一版起**不再每次启动都弹气泡提示**，所以看不到提示是正常的
- [ ] `[3] 关键状态`：有 `[env] 提权=否` 和 `boot ok states=12`
- [ ] `[4] 几何 / 素材`：有 `[geom:` 开头的一行，且里面有
      **`裁掉=0px`**、**`出屏=0px`**、**`气泡出框=0px`** 三个数
- [ ] `[5] pet.err.log 末尾`：显示 `(空)` 最好；有内容请照抄给我
- [ ] 最后一行 `完整日志:` 指向的路径**确实存在**

> 上一次你的 `[2]`~`[5]` 全空，是因为桌宠把日志写到了 `v1\runtime\`，
> 而启动器只在 `<根>\runtime\` 找。已修（现在两个目录都会找）。所以这一段
> **本身就是回归测试**：只要不再全空，就说明修对了。

## 2. 角色显示（最关键，肉眼）

- [ ] 她是**整只都在**：脚、身体、头都不缺（不是"半截"，也不是只剩头）
- [ ] 她的**脚离窗口底边有一点点空隙**（这是设计：素材底部 4% 是留白）
- [ ] 拖动她之后，仍然整只都在（拖到屏幕四角各试一次）
- [ ] 点一下她，会冒一句台词

## 3. 气泡位置

- [ ] 有气泡时：**尾巴搭在她头顶上**（不是悬空、也不是压住脸）
- [ ] 气泡**顶部没有跑到屏幕/窗口外面**（整条都在窗口内）
- [ ] 气泡文字变长（两行）时，以上两条仍然成立

## 4. 右键菜单（你本次报的 bug）—— 这一节请重点试

在**不同高度**右键她，至少试 5 个位置：**头顶、脸、胸口、脚、以及最下端**

- [ ] 每一个位置：菜单 **5 项全部可见**（设置…/强制可交互 60 秒/强制穿透 5 秒/
      清除全部气泡/退出），**「退出」不被切掉**
- [ ] 菜单右边也不出窗口（她贴屏幕右边缘时再试一次）
- [ ] 右键的**瞬间她本人不跳动**（窗口会向上撑开，但角色应该原地不动）
- [ ] 点「设置…」→ 设置窗口能打开
- [ ] 关掉设置窗口后，桌宠窗口**缩回原来大小**，她还在原位
- [ ] 菜单打开时点空白处 → 菜单消失，窗口**缩回原来大小**
- [ ] 缩回后**点击穿透仍然正常**：点她旁边的透明区域，能点到下面的桌面/窗口

## 5. 收尾

- [ ] `Ctrl+Alt+S` 能打开设置
- [ ] `Ctrl+Alt+Q` 能退出（或右键 → 退出）
- [ ] 退出后任务管理器里没有残留 `presage-pet.exe`
